# Tic-Tac-Toe with a Heuristic AI Agent

A command-line Tic-Tac-Toe game where the computer selects moves by evaluating possible board states with a heuristic utility function.

## Features
- Human vs computer mode
- Human vs human mode (available in the script)
- Board-state evaluation
- Positional preference for center and corners
- Win, loss and draw detection

## Concepts demonstrated
AI agents, state evaluation, utility functions, game states and heuristic decision-making.

## Requirements
- Python 3.9 or later
- Jupyter Notebook (optional, for the notebook)

## Run
```bash
python tictactoe_play.py
```

## Limitation
This is a heuristic agent, not a Minimax search implementation. It may make suboptimal moves in some positions.
